## 1. Camera — the reference angle

Rotate the camera rig around the vertical axis so the field is seen obliquely, as in the reference image. Target: **yaw 24° to the right of the field axis, pitch ~54°, FOV 48**, height and distance adjusted so the full 18-unit width and two bars ahead stay on screen at 2400×1080 with margin. Look-at point remains the window centre. The near edge of the field should run diagonally across the lower part of the screen, not horizontally.

Input stays **world-relative**: joystick up = down the field, regardless of the camera yaw. Expose `CAMERA_YAW_DEG` and `INPUT_CAMERA_RELATIVE := false` as constants so both can be flipped for the morning playtest. Verify the death line is still clearly visible as a line, not a point.

## 2. Pacing

- `SONG_START_OFFSET_S = 8.0` for level 1. Playback starts 8 s into the track, so the run-up is ~8.6 s, not 16. Rehearsal (gate opening moving in warning colour) still happens during that run-up. Levels 2+ use offset 10.0. The beatmap's times are absolute; subtract the offset consistently in BeatClock.
- **Breathers become 2 bars**, not 8. The first 2 bars of each low-energy section: open floor, checkpoint, one note, the demo word for whatever the next wave introduces. The remaining bars of that section become **Pressure** density using only types already introduced.
- **No empty bars after the first checkpoint**, except the two breather bars per section.
- Wave 1: a gate **every bar** (not every second bar), pits in between where the fairness validator allows. Rate stays `bar` in level 1.

## 3. In-level ramp

Density within a level rises wave by wave. Define per level a `density_curve` — a multiplier per wave applied to hazard count per bar: level 1 = `[1.0, 1.15, 1.3, 1.5, 1.7]`. Level 1 waves reach `types_per_bar = 2` in wave 5 (a compatible pair, see §6). The outro is not a wind-down anymore: outro = wave-5 density, ends on the goal.

## 4. Orbiters

- Wave 4 in level 1: orbiters on **at least 6 of 8 bars**. Orbiter pairs (opposite rotation) allowed from wave 5 onward in level 1, and freely from level 3.
- Orbiter orbit radius 3, period one bar, unchanged. Add a variant with period **half a bar** for levels 4+.

## 5. Score — distance and deaths

Replace the notes-first scoring:

```
distance_points = floor(furthest_song_progress * 1000)     # 0–1000 for the level
death_penalty   = deaths * 40
note_bonus      = notes * 15 * combo_max                     # notes are a bonus, not the score
score           = max(0, distance_points - death_penalty + note_bonus)
```

Show on the goal label: distance %, deaths, notes, score. Persist best score per level in `progress.gd`. The progress bar's "best" marker now reflects furthest progress as before. This is what the Talo leaderboard will post later; don't wire Talo now.
